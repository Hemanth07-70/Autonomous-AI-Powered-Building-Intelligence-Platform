# Definition of Done (DoD)

A feature or user story is only considered **Done** when:
1. Code implements all Acceptance Criteria.
2. Code strictly adheres to `CODE_STYLE.md`.
3. Unit tests cover >90% of new branches.
4. Integration tests verify core path functionality.
5. CI pipeline passes completely (Green build).
6. Documentation (`design/`) is updated if architecture shifted.
7. PR is approved by at least 1 core maintainer.
