# Submission Deliverables Checklist

This checklist maps your repository to the required deliverables from the evaluation portal.

## 1) Fully Functional Source Code
Status: COMPLETE

Evidence:
- Backend orchestration and APIs: backend/app
- Agent orchestration: backend/app/agents
- EnergyPlus adapter and digital twin: backend/app/energyplus
- Simulation orchestration: backend/app/scheduler
- Frontend dashboard and control UI: frontend/app

Upload guidance:
- Submit repository URL directly.

## 2) Building Models (.idf files)
Status: MISSING IN REPO (at scan time)

Expected contents:
- Baseline building model file (e.g., baseline.idf)
- Runtime-modified model file(s) generated by control loop

Action required:
- Add baseline and modified IDF files to submission/building-models/
- Include a short readme with what changed (setpoints, schedules, control params).

## 3) Quantitative Savings Dashboard / Data Export
Status: PARTIAL

Existing:
- Frontend dashboard pages and analytics shell exist.
- No explicit export artifact proving baseline-vs-optimized kWh reduction found at scan time.

Action required:
- Produce one CSV or PDF showing baseline vs optimized metrics and comfort constraints.
- Use submission/QUANT_SAVINGS_TEMPLATE.csv as a starter.

Required formula:
- Percent reduction = ((Baseline kWh - Optimized kWh) / Baseline kWh) * 100
